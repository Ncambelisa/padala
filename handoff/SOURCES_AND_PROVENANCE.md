# Sources and provenance

## Supplied application baseline

Primary source: `/mnt/data/Padala-NextJS-Python.zip`, originally supplied in this conversation. All 66 application/documentation/assets from that archive are carried into this bundle without application-source changes. Its `README.md`, `docs/TEST-REPORT.md`, `docs/SECURITY-AND-LIMITS.md`, API specification and screenshots remain included.

Current behavior was checked against the extracted manifests, launcher, API routes, schemas, models, services, configuration and tests. The backend suite was rerun during packaging. Historical browser screenshots and harness results remain historical artifacts; they are not newly captured Next.js production screenshots.

## New handoff material

`START_HERE.md`, `AGENTS.md`, `CODEX_START_PROMPT.md`, `REQUIREMENTS.md`, `handoff/*`, the read-only preflight and archive verification scripts, and `FILE_MANIFEST.json` were added for this transfer. They restate the owner's product, distinguish code from proposed future features, and organize local work. They do not add bank confirmation, payments, billing or production approval.

Any proposed engineering priorities or acceptance gates are new recommendations, explicitly separated from current implementation. The original earlier HTML-only or other Python starter packages are intentionally not included to avoid two competing codebases.
